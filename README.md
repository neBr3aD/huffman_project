# Huffman Archiver Bot

Telegram-бот для сжатия файлов `.txt` и распаковки архивов `.huff`. Алгоритм Хаффмана и структуры данных реализованы на C++, тг-бот использует их через `pybind11`.

## Как работает алгоритм

При сжатии программа рассматривает файл как последовательность байтов и подсчитывает, сколько раз встречается каждый байт. Затем она строит бинарное дерево Хаффмана:

1. Для каждого байта с ненулевой частотой создаётся узел дерева.
2. Из упорядоченного списка выбираются два узла с наименьшими частотами. Они объединяются в родительский узел, частота которого равна сумме их частот.
3. Объединение повторяется, пока не останется корень дерева.
4. Путь от корня к листу задаёт код байта: переход влево добавляет `0`, вправо — `1`. Часто встречающиеся байты получают более короткие коды.
5. Коды исходных байтов записываются последовательно и упаковываются в выходные байты.

В архив записываются сигнатура `HUFF`, таблица частот и точное количество закодированных битов. При распаковке по таблице частот строится такое же дерево, затем поток битов проходит по дереву до листьев, восстанавливая исходные байты. Для одинаковых частот используется стабильное правило упорядочивания, чтобы дерево при распаковке совпадало с деревом при сжатии.

## Особенность проекта

В проекте структуры данных реализованы самостоятельно, без использования контейнеров STL для основных операций алгоритма:

- `MyString` — динамическая строка с управлением памятью, копированием и перемещением;
- `HashTable<T>` — хеш-таблица с цепочками для хранения кодов символов и подсчёта частот;
- `DoubleOrderedList<T>` — упорядоченный двусвязный список, используемый при построении дерева;
- `HuffmanNode` и `NodeWrapper` — узлы дерева Хаффмана и обёртка для упорядочивания по частоте.

## Устройство проекта

- `src/pybind_wrapper.cpp` — C++-функции сжатия и распаковки, доступные из Python;
- `src/main.cpp` — отдельная консольная программа для сжатия и распаковки;
- `include/` — реализации алгоритма и пользовательских структур данных;
- `bot.py` — Telegram-интерфейс для отправки файлов и вызова C++-модуля.

## Требования

- Python 3.9 или новее
- CMake 3.16 или новее
- Компилятор с поддержкой C++17
- Средства разработки Python

### macOS

Установите инструменты командной строки Xcode (`xcode-select --install`), Python 3 и CMake. CMake можно установить, например, через Homebrew.

### Linux

Установите Python 3.9+, CMake, компилятор C++17 и заголовки/средства разработки Python с помощью пакетного менеджера вашей системы. Названия пакетов и команды установки зависят от дистрибутива.

### Windows

Установите Python 3.9+, CMake и Visual Studio Build Tools с workload «Desktop development with C++» (или Visual Studio с поддержкой разработки на C++). При установке Python включите его в `PATH`.

## Установка и сборка бота

Клонируйте репозиторий и перейдите в папку проекта. Подставьте URL своего GitHub-репозитория:

```sh
git clone <URL-репозитория>
cd huffman_project
```

Создайте виртуальное окружение и установите зависимости. `pybind11` используется для сборки C++-модуля, а `aiogram` — для Telegram-бота.

#### macOS и Linux

```sh
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
cmake -S . -B build -DPython3_EXECUTABLE="$PWD/venv/bin/python"
cmake --build build --parallel
```

#### Windows (PowerShell)

```powershell
py -3 -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
cmake -S . -B build -DPython3_EXECUTABLE="$((Resolve-Path .\venv\Scripts\python.exe).Path)"
cmake --build build --parallel
```

Собирается C++-модуль, который бот импортирует как `huffman_archiver`. Для CMake важно указать тот же Python, в который установлены зависимости. После сборки модуль появится в `build/`; `bot.py` ищет его именно там.

Создайте в корне проекта файл `my_token_bot.py`:

```python
TOKEN = "вставьте-сюда-токен-от-BotFather"
```

Файл `my_token_bot.py` исключён из Git через `.gitignore`: не добавляйте его в коммиты и не публикуйте токен.

Запустите бота из корня проекта:

```sh
python bot.py
```

В Windows запустите его Python из виртуального окружения:

```powershell
.\venv\Scripts\python.exe bot.py
```

В терминале должно появиться сообщение `Бот запущен`. Откройте бота в Telegram, отправьте `/start`, затем попробуйте отправить `.txt` файл для сжатия или `.huff` архив для распаковки. Для остановки нажмите `Ctrl+C`.

## Сборка консольной программы (необязательно)

Для работы Telegram-бота эта программа не требуется: бот использует собранный выше модуль `huffman_archiver`. CMake собирает консольную программу вместе с модулем. Запустите её, передав путь к файлу:

```sh
./build/huffman путь/к/файлу.txt
```

В Windows:

```powershell
.\build\huffman.exe "C:\путь\к\файлу.txt"
```

Если запустить программу без аргумента (`./build/huffman` на macOS/Linux или `.\build\huffman.exe` в Windows), она запросит путь к файлу.

Программа создаст `archive.huff` и `restored.txt` в текущей рабочей папке. Это консольная программа: она не загружает файлы через интерфейс. Загрузка файлов в Telegram доступна при запуске бота командой `python bot.py`.
